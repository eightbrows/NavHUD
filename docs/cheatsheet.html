NavHUD チートシート

移動目標案内アプリ ・ 20261010-D02 時点 ・ 画面は REPLAY（記録の再生）の例

1 画面の見方

  1. HDG 方位の取り方。タップで GPS / HYBRID / COMPASS
  2. WP 下の WP ボタン列を出す / 隠す
  3. ⇄ LIVE / REPLAY GPS と記録の再生を切り替え
  4. FILE 再生する track.csv を選ぶ（REPLAY のみ）
  5. ARC / N-UP 進行方向が上 / 北が上
  6. ⚙ 設定
  7. 数値の4行（「数値の4行」の表）
  8. 機首の線と三角 今向いている方向
  9. 距離環と数字 自機からの距離。単位は m、1k = 1km。前後左右の4か所
  10. 次の WP の文字 上から 距離・名前・方位（真北基準）。画面の外にあるときは、その方向の端に出る
  11. WP の印と線 次の WP はマゼンタ。到達済みは暗いグレー、無効はグレーの破線
  12. 自機
  13. 軌跡 細い線 = 読み込んだ記録、太い線 = 走った跡
  14. − / 縮尺 / ＋ 数字は1つ目の距離環の距離。塗りつぶし = AUTO、枠だけ = 手動、黄色の PAN = パン中
  15. 再生の操作（REPLAY のみ。2 操作）
  16. WP ボタン列 左端は「WP設定」。マゼンタ = 次、塗りつぶし = 到達済み、グレー = 無効
  17. 標高プロファイル（高度のグラフ） 現在地 → 次の WP → その先

3 AUTO の縮尺

  • 次の WP が画面に入る縮尺を、下限〜上限（初期値 50m〜500m）の中で自動で選ぶ。
  • 近づくと拡大: WP まで「縮尺の数字 × 1.3」以内が 5 秒続くと1段。
  • 到達するまで縮小しない: 拡大したあとは、WP が横へ外れてもそのまま（WP から大きく離れたときだけ縮小）。
  • 通過して 10 秒後に、次の WP に合わせる。
  • 入りきらない WP は、画面の端の文字（図の 10）で示す。
  • ＋ / −・ピンチで手動になる。縮尺の数字をタップすると AUTO に戻る。パン中の ＋ / −・ピンチは AUTO を切らない。

4 WP の到達の判定 （次の WP だけ）

到着WP から 30m 以内に入る（到達半径。WP ごとに変えられる）
真横走行中に 150m 以内で WP が真横〜後ろになり、いちばん近づいた所から 10m 離れる
通過予備。300m 以内に近づいたあと、50m 以上離れた状態が 5 秒続く
  • 到達すると、自動で次の WP に進む。
  • 「WP設定」の一覧に理由が出る。例: 真横 08:12:34 最接近 42 m。ほかに 半径・手動・シーク。
  • 違っていたら、WP ボタンのタップで戻す。

6 ファイルの読み込み

WP リスト: 起動時に「前回のリスト / リストを選ぶ / リストなし」。あとからは「WP設定」→ インポート。

  • CSV（読み書き）: 1行目は見出し lat,lon,ele,name,target_time,deadline_time,enabled,radius。必須は lat と lon。時刻は 9:30 の形。Excel で編集できる。
  • GPX（読むだけ）: <wpt> の位置・name・ele・time（目標時刻）。
  • 貼り付け: Google マップでコピーした座標 34.69370, 135.50230。
  • 編集した WP はアプリに保存されない。エクスポート（CSV）して残す。

軌跡（再生用）: ⇄ で REPLAY にして、FILE で track.csv を選ぶ。次回からは自動で開く。

  • CSV で、見出しに latitude・longitude と、時刻の epoch_ms か utc_iso8601 が必要。
  • あれば使う列: altitude_ellipsoid_m・speed_mps・bearing_deg・bearing_acc_deg・horizontal_acc_m。
