NavHUD チートシート

目標針路案内アプリ ・ 20261122-D02 時点 ・ 図は REPLAY（記録の再生）の ARC の例（自動車のプリセット。背景地図あり）

1 画面の見方

  1. 移動のプリセット 今のプリセットの名前（自動車 水色・歩行 緑・カスタム 紫）。押しても変わらない（設定の帯で選ぶ）。位置がないときは、その右のまん中に赤い NO FIX
  2. ARC / N-UP 進行方向が上 / 北が上
  3. ⚙ 設定。幅が足りない画面では、上部バーの文字が少し小さくなる
  4. 数値の4行 左の列 = 時刻と WP、右 = 自機（「数値の4行」の表）
  5. 機首の線と三角 今向いている方向
  6. 距離環と数字 自機からの距離。単位は m、1k = 1km。前後左右の4か所
  7. 次の WP の文字 上から 距離・名前・方位（真北基準）。画面の外にあるときは、その方向の端に出る
  8. WP の印と線 次の WP はマゼンタ。到達済みは暗いグレー、無効はグレーの破線
  9. 自機
  10. 軌跡 細い線 = 読み込んだ記録、太い線 = 走った跡
  11. − / 縮尺 / ＋ 数字は1つ目の距離環の距離。塗りつぶし = AUTO、枠だけ = 手動、黄色の PAN = パン中
  12. 左の列 ⇄ LIVE / REPLAY。REPLAY のときは FILE・スライダー・再生の操作（2 操作）
  13. WP ボタン列 左端の「WP」で WP設定。マゼンタ = 次、塗りつぶし = 到達済み、グレー = 無効
  14. 標高プロファイル（高度のグラフ） 現在地 → 次の WP → その先。初期値は OFF（設定で出す）

背景地図の見方 （いちばん下に暗く描く）

  • 空港 黄緑の飛行機。民間は塗りつぶし（大は丸い輪付き）、自衛隊・米軍は白抜き。大 = 滑走路 2,000m 以上、小 = 600m 以上。右上に略号、薄い塗りは敷地
  • 滑走路 黄緑の線（太さは実際の幅）。両端の先の破線は延長線
  • 山頂 桃色の三角。大きい順に 高（1,500m 以上の目印の山）・中・低
  • 道路 高速道路は青、国道は赤、県道は茶。新幹線は紫の実線、在来線は破線
  • パン中 地図の中心に小さな十字

3 AUTO の縮尺

  • 次の WP が画面に入る縮尺を、詳細の下限〜広域の上限（初期値 50m〜250m）の中で選ぶ。
  • 近づくと詳細へ: WP まで「縮尺の数字 × 1.3」以内が 5 秒続くと1段。詳細にしたら到達まで広域にしない。
  • WP を過ぎて 10 秒後に次の WP に合わせる。入りきらない WP は画面の端の文字（図の 7）。
  • ＋ / −・ピンチで手動。縮尺の数字のタップで AUTO に戻る（パン中は AUTO を切らない）。

4 WP の到達の判定 （次の WP だけ。かっこは歩行）

到着WP から 30m（15m）以内に入る（到着半径。WP ごとにも変えられる）
真横11 km/h（2 km/h）以上で、150m（50m）以内で WP が真横〜後ろになり、いちばん近づいた所から 10m（5m）離れる
通過予備。300m（50m）以内に近づいたあと、50m（10m）以上離れた状態が 5 秒（3 秒）続く
  • 到達すると自動で次の WP へ。WP設定の一覧に理由（例 真横 08:12:34 最接近 42 m）。違っていたら WP ボタンのタップで戻す。

6 ファイルの読み込み

WP リスト: 起動すると前回のリストを開く。あとからは「WP」→ インポート（ファイルの画面）。「WP」→ クリア で外すと次回も開かない。

  • CSV（読み書き）: 見出し lat,lon,ele,name,target_time,deadline_time,enabled,radius。必須は lat と lon。時刻は 9:30。Excel で編集できる。
  • GPX（読むだけ）: <wpt> の位置・name・ele・time。貼り付け: 34.69370, 135.50230。
  • 編集した WP はアプリに保存されない。エクスポート（CSV）して残す。WP エディタ（ブラウザ）でも作れる。

軌跡（再生用）: 左の列の ⇄ で REPLAY、その下の FILE で track.csv か GpsLogger の zip（セッションの一覧から1つ）を選ぶ。次回からは自動で開く。クリア はファイルの画面。

  • track.csv は latitude・longitude と epoch_ms か utc_iso8601 が必要。
  • 違う種類のファイルは読み込まずに知らせる。読み込むと数秒だけ件数のひとことが出る。
